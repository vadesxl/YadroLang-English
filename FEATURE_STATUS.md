# Feature status

## Implemented
Functions, variables, recursion, if/else, while, i64/bool inference, direct string printing, LLVM IR/native objects, capability mandates, explicit/implicit multi-label analysis, strict declassification, JSON/SARIF CLI, custom JSON policies, Yadro MCP tool-graph scanning, cross-platform CI.

## Experimental
Type inference across recursive call graphs, MCP excessive-agency heuristics, audit evidence format, external ABI v1.

## Planned
Runtime ABI library, signed evidence, official framework adapters, packaging/binaries, richer string and memory model, benchmark baselines.

## Not supported
GC, VM/interpreter runtime, arbitrary vendor MCP manifest import, dynamic policy changes, arbitrary string storage/return, full memory ownership, microarchitectural side-channel proof.
